# SBF Binnen — Словарь для практического экзамена (Motor + Segeln)
# SBF Binnen — Wortschatz für die praktische Prüfung (Motor + Segeln)

## Контекст / Kontext

Этот словарь покрывает ВСЮ лексику из листов команд для практической части экзамена SBF Binnen —
мотор и парус. Слова организованы по тематическим блокам: от ролей на борту до звуковых сигналов.
Каждое слово снабжено примером из реальных экзаменационных команд.

Dieser Wortschatz deckt ALLE Begriffe aus den Kommandoblättern für die praktische Prüfung
SBF Binnen ab — Motor und Segeln. Die Wörter sind in thematische Blöcke gegliedert.
