# SBF Binnen — Учебный план для подготовки к теоретическому экзамену
# SBF Binnen — Lernplan für die theoretische Prüfung

## Контекст / Kontext

Дима готовится к теоретическому экзамену на Sportbootführerschein Binnen (SBF Binnen) — 
удостоверение на управление прогулочным судном на внутренних водных путях Германии.
Экзамен состоит из 30 вопросов (из 300 возможных), на немецком языке, формат — множественный выбор.
Текущий уровень немецкого: A1 → A2. Экзамен запланирован примерно на середину мая 2026.

Dima bereitet sich auf die theoretische Prüfung für den Sportbootführerschein Binnen (SBF Binnen) vor — 
einen Führerschein für Sportboote auf Binnenschifffahrtsstraßen.
Die Prüfung besteht aus 30 Fragen (aus 300 möglichen), auf Deutsch, im Multiple-Choice-Format.
Aktuelles Deutschniveau: A1 → A2. Prüfung geplant ca. Mitte Mai 2026.

## Рекомендации для преподавателя / Empfehlungen für die Lehrerin

### Как использовать этот материал / Wie dieses Material verwenden

1. **Каждую неделю — 1 блок** из списка ниже (~15-25 слов). За 8 недель — все блоки.
2. **На уроке:** разбирать слова в контексте предложений из экзамена (примеры указаны).
3. **Домашнее задание:** Quizlet-карточки по текущему блоку + упражнения ниже.
4. **Формат экзамена:** вопрос + 4 варианта ответа. Ключевой навык — понимание различий между похожими ответами.

### Типы упражнений / Übungstypen

- **Lückentext (заполни пропуски):** предложения из экзамена с пропущенными ключевыми словами
- **Zuordnung (соотнесение):** термин ↔ определение; знак ↔ значение
- **Richtig/Falsch (верно/неверно):** утверждения о правилах судоходства
- **Mündliche Beschreibung (устное описание):** описать ситуацию на воде, используя термины
- **Paraphrase (перефразирование):** объяснить правило своими словами
- **Prüfungssimulation (симуляция экзамена):** разбирать реальные вопросы вместе

### Что было бы ценно узнать от преподавателя / Input von der Lehrerin

- Какие грамматические конструкции Дима уже усвоил? (падежи, времена, модальные глаголы)
- С какими типами предложений возникают трудности? (придаточные, пассив, сослагательное)
- Рекомендуемый темп — реалистично ли 1 блок в неделю для домашней работы?
- Есть ли предпочтения по формату домашних заданий?
