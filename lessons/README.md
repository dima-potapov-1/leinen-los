# Leinen los! — Lesson Materials

Lesson-by-lesson materials for SBF Binnen exam prep combined with German language learning.

## Context

- **Exam:** Sportbootführerschein Binnen (SBF Binnen) — theoretical, 30 questions from 300, multiple choice, in German
- **Target date:** Mid-May 2026
- **German level:** A1 → A2
- **Strategy:** Learn German *through* the exam material, not separately

## Lesson Format (agreed 2026-03-23)

Each lesson has two parts:

1. **Vocabulary drill** — oral quiz on the week's word block
2. **Exam questions** — analyze real questions for both language and content

### Homework

- Daily Quizlet flashcards (recognition: German → meaning)
- Fill-in-the-blank exercises from real exam sentences
- Nebensätze grammar drills (weil/wenn/dass) using maritime vocabulary
