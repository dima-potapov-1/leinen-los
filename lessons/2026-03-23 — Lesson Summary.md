# German Lesson — Maritime Vocabulary & Exam Prep

**Date:** Mar 23, 2026
**Format:** Regular German language class with teacher
**Theme:** Unifying German learning with Sportbootführerschein (boating license) exam preparation

---

## Context

Dima is combining two parallel efforts — learning German and preparing for the German boating license exam (300 questions in German). Rather than studying them separately, the idea is to use the exam material as the primary content for German lessons: learn the language *through* the domain.

---

Dima showed the teacher materials he generated using an AI agent (Cursor + Claude):

**Teacher's input requested:** The AI agent can generate structured lesson materials (exercises, texts, grammar drills) — the teacher is invited to provide pedagogical guidance so the generated materials match her methodology.

**Agreed:** Dima will update the AI's instructions based on teacher's feedback and generate tailored materials for each lesson.

---

## 3. Exam Questions Worked Through

Several real exam questions analyzed for both language and content:
- **Luvgierig sailing:** Why a well-trimmed sailboat should have slight weather helm (safety — auto-heads into wind if control is lost)
- **Motorboat right-of-way:** How two motorboats on opposing courses yield to each other
- **Navigation lights:** What lights are prescribed for sailing vessels and convoys
- **Overtaking rules:** Overtaking from port vs. starboard side

Key insight: working from exam questions provides richer context than isolated vocabulary lists — some terms only make sense within the question's scenario.

---

## 4. Grammar Encountered

Not planned, but surfaced naturally from exam material:

- **Subordinate clauses** (Nebensätze) with `weil`, `wenn`, `dass` — verb goes to end
  - Contrast: `denn` keeps normal word order (two main clauses)
- **Genitiv case:** *Fahrzeug eines Schleppverbands* — encountered but not formally taught yet
- **Participles as adjectives:** infinitive + `-d` → *vorausfahrend* (going ahead)

## 6. Exam Strategy

The goal is **receptive competence**, not production: understand the German question well enough to recognize which answer fits. No need to translate Russian → German. Priority is German → meaning association.
